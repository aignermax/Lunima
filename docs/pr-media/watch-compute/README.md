# Watch it compute: actual Counter actions

These images are real headless MainWindow captures from `WatchComputeActionJourneyTests`, not mockups or captures of the user's running app.

The English and German flows open the shipped 2-bit Counter through Home, click Build logic network, Step clock, Run and Stop, recover the hidden Logic dock, and finish using the visible Done button. No input values are injected. The captures show the actual Stop target, compact cue, committed C bus state and clock waveform after the first clock step.

- [English](en-stop.png)
- [German](de-stop.png)

Long explanations remain available through the help button. The guide cannot skip required actions with Next. It returns to Build after network invalidation and distinguishes closing the dock from intentionally pressing Stop.
