# Lunima Design System

Every view uses the shared design system in `CAP.Avalonia/Styles/`. It is included once in
`App.axaml` (and in the headless `ScreenshotTestApp`) via `LunimaTheme.axaml`.

| File | Contents |
|---|---|
| `Tokens.axaml` | Colors, type scale, spacing, radii, control heights, motion durations |
| `FluentOverrides.axaml` | Fluent theme resource keys mapped onto the tokens (untouched controls still match) |
| `Icons.axaml` | Lucide line icons as `StreamGeometry` (`Icon.<Name>`), generated by `scripts/lucide_to_axaml.py` |
| `Typography.axaml` | `TextBlock` classes |
| `Controls.axaml` | Button / input variants |
| `Containers.axaml` | `Border` surface classes, chips, lists, splitters |

`UnitTests/Architecture/DesignTokenGuardTests` fails when a view adds a hex color or a font
size below 11. Remaining literals in not-yet-migrated views are listed in
`UnitTests/Architecture/DesignTokenBaseline.json`. The baseline only ever goes down: when you
migrate a file, lower or remove its entry.

## Rules

1. **No hex colors in views.** Use `{DynamicResource Brush.*}`. If no token fits, add one to
   `Tokens.axaml` with a role name (what it is for), not a color name.
2. **No ad-hoc font sizes.** Use a `TextBlock` class (`title`, `subtitle`, `caption`, `label` …)
   or `{DynamicResource FontSize.*}`. Nothing below 11 px.
3. **One control height.** Buttons and inputs are 28 px (`ControlHeight`); dense property grids
   may use the `compact` class (24 px). Never set `Height`/`Padding` on a button to resize it.
4. **Color means state.** The accent marks the primary action, selection and focus. Green / amber
   / red / cyan only signal success / warning / danger / info. Headings are neutral.
5. **One primary action per surface** (`Button.primary`). Everything else is secondary (no
   class), `ghost`, or `danger` for destructive actions.
6. **Icons, not emoji.** Use `<controls:Icon Data="{StaticResource Icon.Save}"/>`
   (`xmlns:controls="using:CAP.Avalonia.Controls"`). Icons inherit the text color, so they
   follow hover, checked and disabled states. Add missing icons by name from
   [lucide.dev](https://lucide.dev) to the list in `scripts/lucide_to_axaml.py`, then regenerate.
7. **Spacing on the 4 px grid**: 4 · 8 · 12 · 16 · 24 · 32 (`Space.*`, `Padding.*`).
8. **Empty states are designed**: an icon, one sentence, and the action that fills the area.
9. **Motion is quick and quiet**: hover/press transitions use `Motion.Fast` (120 ms); panels and
   overlays fade/slide with `Motion.Normal` (200 ms). Nothing loops unless it shows live activity.

## Tokens

**Surfaces** (back to front): `Brush.Surface.Canvas` · `Base` (window) · `Panel` (docked areas)
· `Raised` (cards, buttons) · `Hover` · `Pressed` · `Overlay` (flyouts, tooltips) · `Input`.

**Borders**: `Brush.Border.Subtle` (hairlines between areas) · `Default` (controls) · `Strong`
(hover) · `Focus`.

**Text**: `Brush.Text.Primary` · `Secondary` · `Tertiary` (hints, labels) · `Disabled` ·
`OnAccent` · `Link`.

**Accent & state**: `Brush.Accent` (+ `.Hover`, `.Pressed`, `.Subtle`, `.SubtleHover`),
`Brush.Success|Warning|Danger|Info` (+ `.Subtle` for chip / banner backgrounds).

**Type**: `FontSize.Caption` 11 · `Body` 12 · `BodyLarge` 13 · `Subtitle` 14 · `Title` 16 ·
`Headline` 20 · `Display` 26. UI font Inter (`Font.Ui`), numbers and code `Font.Mono`.

**Shape**: `Radius.S` 4 · `M` 6 (controls) · `L` 10 (cards, overlays) · `Pill`.

## Classes

| Element | Classes |
|---|---|
| `TextBlock` | `display` `headline` `title` `subtitle` `body` `strong` `caption` `label` `secondary` `muted` `mono` `success` `warning` `danger` `accent` |
| `Button` | *(none)* = secondary · `primary` · `ghost` · `danger` · `icon` · `toolbar` (+ `active`) · `link` |
| `ToggleButton` | `ghost` · `icon` · `toolbar` (`:checked` shows the active mode) |
| `TextBox` / `ComboBox` / `NumericUpDown` | `compact` · `mono` (TextBox) |
| `Border` | `panel` `card` (+ `interactive`) `toolbar` `statusbar` `overlay` `divider` `empty-state` `chip` (+ `success` `warning` `danger` `info` `accent`) |

## Examples

```xml
<!-- Toolbar button with icon and tooltip -->
<Button Classes="toolbar" ToolTip.Tip="Save (Ctrl+S)" Command="{Binding SaveCommand}">
  <controls:Icon Data="{StaticResource Icon.Save}"/>
</Button>

<!-- Dialog footer: one primary action -->
<StackPanel Orientation="Horizontal" Spacing="8" HorizontalAlignment="Right">
  <Button Content="Cancel" Command="{Binding CancelCommand}"/>
  <Button Classes="primary" Content="Import" Command="{Binding ImportCommand}"/>
</StackPanel>

<!-- Empty state -->
<Border Classes="empty-state">
  <StackPanel Spacing="8" HorizontalAlignment="Center">
    <controls:Icon Data="{StaticResource Icon.CircleCheck}" Size="24" Foreground="{DynamicResource Brush.Text.Tertiary}"/>
    <TextBlock Classes="secondary" Text="No checks run yet" HorizontalAlignment="Center"/>
    <Button Classes="primary" Content="Run design checks" HorizontalAlignment="Center"/>
  </StackPanel>
</Border>
```

## Canvas

The design canvas is drawn in C#; its colors live in `CAP.Avalonia/Controls/Rendering/CanvasPalette.cs`
and follow the same palette (accent = selection, danger = blocked / unroutable, warning = DRC hints).
