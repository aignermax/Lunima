# X-2026-w46-digital-photonic-courses: Is digital, logic-level photonic computing taught hands-on anywhere?
- status: proposed
- method: desk-research
- autonomy: autonomous
- assumption: University courses exist that teach digital, logic-level photonic or optical computing with hands-on design or simulation work by students, so a ladder tool would have an existing course slot to fill.
- hypotheses: H7
- budget: 0 USD; one scout run (≤ 2 h agent time), no people contacted

This replaces the course-ladder desk check proposed in 2026-w45 (never registered in this
repository). Last week's critic found that the w45 version would pass on neuromorphic or ML
courses alone and had no failure branch. This version adds both.

## Pre-registration
- protocol:
  - Run each query below in general web search and read the first 20 results:
    - `optical computing course syllabus logic gates`
    - `photonic computing course university digital logic`
    - `all-optical logic gates lecture course lab`
    - `photonic logic course simulation assignment`
    - `optical digital computing course 2025`
    - `silicon photonics logic gates student project course`
    - `Vorlesung optisches Rechnen Logikgatter`
    - `photonische Logik Vorlesung Übung`
  - Follow course-catalogue links from the results.
  - A candidate needs a public course page or syllabus for an offering in academic year
    2024/25, 2025/26 or 2026/27.
- classification:
  - **D** (digital, logic-level): the syllabus names optical or photonic logic gates, Boolean
    logic, adders, latches or flip-flops, or digital optical processors.
  - **N**: neuromorphic, analog or ML-accelerator optical computing.
  - **P**: device or PIC design without computing.
  - **Hands-on**: the page names a lab, a design project, a simulation assignment, or a software
    tool used by students.
  - Every candidate is recorded with URL, institution, year, class, hands-on yes/no, and the
    tools named.
- success: at least 3 distinct courses (different institutions, or different course codes) are
  classified D and hands-on.
- failure: 2 or fewer such courses after the full protocol.
- interpretation, fixed now:
  - **Failure:** there is no existing course slot. Course adoption would need educators to create
    new course content, which weakens H7's riskiest assumption. Interview #1597 then targets
    self-learners and workshop or MOOC organisers instead of course instructors (see DR-0002).
  - **Success:** the instructors of the qualifying courses become #1597's target profile, through
    maintainer-approved outreach only.
  - The N-class count is recorded as context for H9 but is not scored.
- measurement: the scout runs the protocol in the 2026-w47 run, enters qualifying courses as
  evidence entries and appends the full candidate table under Results; the critic checks the D
  classification by reading the cited syllabi.
- timebox: 2026-11-27
